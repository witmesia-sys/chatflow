# ChatFlow AI — WhatsApp Webhook

Bot de WhatsApp con IA para negocios B2B latinoamericanos.

## Stack
- Node.js + Express
- Groq API (llama-3.3-70b-versatile)
- Supabase (PostgreSQL)
- Meta WhatsApp Business API
- Google Calendar

## Variables de entorno requeridas

Copia `.env.example` a `.env` y completa los valores.

## Desarrollo local

```bash
npm install
node src/index.js
```
